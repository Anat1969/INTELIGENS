# תיקון תמונות בהדפסה ושיפור קריאות

## מה יתוקן
- תמונות בדוחות PDF יוטמעו מראש כנתוני תמונה מקומיים ויציבים, במקום להסתמך על כתובת מרוחקת בזמן ההדפסה.
- בדפי מיזוג, פרופיל ואינטליגנציה בסיסית תיטען תמונת ההדפסה ישירות בעת פתיחת התוכן וגם לאחר החלפת תמונה.
- כתובות התמונות המוצגות במסך ישמרו על רענון מטמון, אך הכתובת תחושב פעם אחת בכל פתיחה כדי למנוע טעינות חוזרות.
- טקסט קריא במסך ובהדפסה יוגדל באופן ברור, בלי לשנות כותרות תצוגה או תוויות מונו זעירות.

## גדלים מרכזיים
- הדפסה: טקסט בסיסי 9.5pt ← 12pt; כותרת ראשית 22pt ← 26pt; כותרות סעיף 9pt ← 11pt; ריווח שורות 1.5 ← 1.6.
- מסך: תיאורי אינטליגנציה 13–15px ← 16–17px; שאלות ותשובות 16–28px יוגדלו לפי תפקידן; תיאור פרופיל 16px ← 17px; תוויות תרשים 14px ← 16px; טקסט ספרייה 11–12px ← 16px.

## פרטים טכניים
- יתווסף `resolvePrintImage(id)` שמעדיף תמונת `data:` מקומית, אחרת מוריד את תמונת המאגר פעם אחת וממיר אותה ל־`data:` באמצעות Blob ו־FileReader.
- שלושת סוגי הדוחות ישתמשו רק במקור המוטמע עבור `<img className="print-img">`.
- בדיקות דפדפן יזריעו PNG אמיתי באחסון המקומי, ייצרו PDF לכל אחד משלושת הדוחות, ויוודאו שבתוצר מופיעים גם התמונה וגם הטקסט המוגדל.
- לבסוף תיבדק תקינות הבנייה.
